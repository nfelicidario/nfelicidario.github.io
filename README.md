# nolanfelicidario.com

Portfolio of Nolan Felicidario, product designer who ships the code. Built with Next.js (static export), TypeScript, Tailwind, and Motion, with Claude Code. Deployed to GitHub Pages.

- `src/app` — pages
- `src/components` — layout and case-study building blocks
- `src/content` — project data and case studies

`stories/` and `raw-assets/` are local-only working folders and are not part of this repo.
